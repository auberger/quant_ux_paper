**Author:** Aurel Berger

**Institution:** ETH Zürich

**Date:** February 2026

---

## Overview

This replication package contains all data, code, and analysis notebooks needed to reproduce the statistical analyses and visualizations reported in the paper. The study examines factors predicting behavioral intention to recommend the Movement Island—an autonomous camera-based movement system for care homes—using an extended Technology Acceptance Model (TAM).

**⚠️ Important Limitation:** This study has a severe sample size limitation (N=16, far below recommended N≥100-150 for stable factor analysis). All results should be interpreted as preliminary methodological demonstration requiring validation with adequately powered samples.

## Variable Codebook

### TAM Constructs (Composite Scores, 1-7 scale)

All constructs measured with three items each on 7-point Likert scales (1 = Strongly disagree, 7 = Strongly agree):

- **PU (Perceived Usefulness)** - Belief that the system would benefit older adults
  - PU1: "This system could help older adults be more physically active"
  - PU2: "This system could provide meaningful benefits for care home residents"
  - PU3: "Using this system would be useful for older adults in care homes"

- **PEOU (Perceived Ease of Use)** - Belief that the system is easy for older adults to use
  - PEOU1: "Older adults could use this system with only a short explanation"
  - PEOU2: "The system would be easy for older adults to learn"
  - PEOU3: "I would describe this system as easy to use for older adults"

- **PE (Perceived Enjoyment)** - Belief that older adults would find the system enjoyable
  - PE1: "Using this system would likely feel fun for older adults"
  - PE2: "Older adults would probably enjoy interacting with this system"
  - PE3: "This system could make physical activity more enjoyable"

- **PS (Perceived Safety)** - Belief that the system is physically safe for older adults
  - PS1: "This system could be used safely by older adults in a care home"
  - PS2: "The system poses minimal physical risk for older adults"
  - PS3: "I would feel comfortable recommending this system regarding safety"

- **BI (Behavioral Intention)** - Willingness to recommend or support the system
  - BI1: "I would recommend this system to people I know who might benefit from it"
  - BI2: "I would support implementation of this system in care homes"
  - BI3: "I would encourage older adults to try this system"

### Demographics

- **Age group** - Categorical (18-24, 25-34, 35-44, 45-54, 55+)
- **Digital technology comfort** - 5-point scale (Not comfortable to Extremely comfortable)
- **Care home familiarity** - Binary (Yes/No: "Do you currently or have you ever had a close relative or friend living in a care home?")
- **Healthcare profession** - Binary (Yes/No: "Do you work in healthcare or a care-related profession?")

## Key Findings

### Sample Characteristics (N=16)
- **Age:** Predominantly 25-34 years (50%)
- **Digital comfort:** High (75% "Very" or "Extremely" comfortable)
- **Care home familiarity:** 38% had close relative/friend in care homes
- **Healthcare profession:** 19% worked in healthcare/care

### TAM Construct Descriptives
All constructs showed high mean ratings (>5.5 on 1-7 scale):
- Behavioral Intention (BI): M=6.10, SD=0.66
- Perceived Usefulness (PU): M=6.00, SD=0.64
- Perceived Safety (PS): M=5.90, SD=0.77
- Perceived Enjoyment (PE): M=5.88, SD=0.76
- Perceived Ease of Use (PEOU): M=5.60, SD=0.70

### Correlations
Strong positive correlations among most constructs:
- PE - PU: r=.83, p<.001
- PE - BI: r=.79, p<.001
- PU - BI: r=.75, p=.001

PEOU showed weaker correlations with other constructs (r=.19-.39).

### Exploratory Factor Analysis
- **5-factor solution extracted** (based on theoretical TAM)
- **Variance explained:** 100% cumulative (as expected with PCA)
- **Factor structure:** Partial recovery only—PEOU and PS reasonably aligned, but PU, PE, and BI showed substantial cross-loadings
- **⚠️ Severe sample inadequacy:** N=16 produces highly unstable factor structures

### Multiple Regression
**Model:** BI ~ PU + PEOU + PE + PS

- **Overall model:** F(4,11)=5.24, p=.013 (significant)
- **R² = .656** (explains 65.6% of variance)
- **Effect size:** Cohen's f²=1.90 (large)
- **Individual predictors:** None significant due to multicollinearity (VIF: 70-356) and insufficient power
- **Standardized coefficients suggest:**
  1. Perceived Enjoyment (β=.51) - strongest
  2. Perceived Usefulness (β=.30)
  3. Perceived Safety (β=.07)
  4. Perceived Ease of Use (β=-.05) - weakest

## Limitations

### Critical Sample Size Issue
- **N=16** is catastrophically below recommended minimums
- **EFA:** Requires N≥100-150 for 15 items (ratio ≥5:1)
- **Regression:** Requires N≥85-180 for reliable inference with 4 predictors
- **Current ratio:** 1.07:1 (EFA) and 4:1 (regression) - severely inadequate

### Consequences
1. **Unstable factor structure** - unlikely to replicate
2. **Wide confidence intervals** - high uncertainty in estimates
3. **Low statistical power** - high Type II error risk
4. **Severe multicollinearity** - cannot isolate unique predictor effects

### Other Limitations
- **Proxy evaluation:** Students/adults assessing technology for older adults (not end users)
- **Brief interaction:** 2-5 minutes with prototype (not sustained use)
- **Convenience sample:** Homogeneous demographics (75% high digital comfort)
